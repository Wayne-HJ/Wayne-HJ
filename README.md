# Tools should just be tools.

I'm Wayne Jiang, a Sydney-based engineer building **itecnet** — a return to what apps were supposed to be.

## The idea

Somewhere along the way, apps stopped serving us and started harvesting us. A flashlight wants your phone number. A calculator wants your real name. Tools caught the login disease.

itecnet stands for one simple idea:

> An app should be one of two things: **a tool, or social.**
> Tools should just be tools — open it, use it, put it down. No accounts. No logins. No nonsense.

## The proof

I don't just talk about it. I ship it:

### [Mypost](https://github.com/Wayne-HJ/Mypost)
A local-first, open-source Postman alternative (MIT). Your requests, environments and history live on your machine — because there is no server to send them to, and no account to sign in to. 中文 / English.

`Electron` `React` `TypeScript`

### [SQLStudio](https://github.com/Wayne-HJ/SQLStudio)
An open-source desktop database workspace for macOS & Windows. Browse data, write queries, inspect schemas across MySQL, MariaDB, PostgreSQL, SQLite, MongoDB and Redis. It opens and it works — that's the whole onboarding flow.

`TypeScript`
